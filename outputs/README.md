
# Generated Outputs

This folder contains charts generated by the Restaurant Sales Dashboard.

## Charts

- `revenue_by_item.png` — compares revenue across menu items.
- `daily_revenue.png` — shows revenue trends across dates.

## Regenerating the Charts

Run the project's main program to regenerate these charts after the analysis workflow has been implemented.

Generated images are project outputs and may be replaced when the program runs again.
