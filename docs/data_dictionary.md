
# Data Dictionary

## Dataset: Restaurant Sales

**File:** `data/restaurant_sales.csv`

**Purpose:** Stores sample restaurant sales records for analysis and visualization.

| Column | Data Type | Description | Example |
|---|---|---|---|
| Date | Date | Date on which the sale occurred | 2026-10-01 |
| Item | Text | Name of the menu item sold | Paneer Tikka |
| Category | Text | Menu category of the item | Starter |
| Quantity | Integer | Number of portions sold | 10 |
| Price | Numeric | Price per portion in Indian rupees | 220 |

## Derived Field

| Field | Calculation | Description |
|---|---|---|
| Revenue | Quantity × Price | Revenue generated by a sales record |

Revenue is calculated by the Python analysis module and is not stored in the original CSV file.

## Notes

- The dataset contains sample records for demonstration and testing.
- Prices are expressed in Indian rupees (INR).
- The current sample dataset contains six records across two dates.
- The dataset is not evidence of actual restaurant business performance.
